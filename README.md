## Security Model

ZISHU TRON enforces security at the **database layer** — never trusting client-side checks.

<table>
<tr>
<th>Node</th>
<th>Public Read</th>
<th>Authenticated Read</th>
<th>Write</th>
</tr>
<tr>
<td><code>products</code></td>
<td>Published only (via query)</td>
<td>Published only</td>
<td>Admin only</td>
</tr>
<tr>
<td><code>updates</code></td>
<td>Published only (via query)</td>
<td>Published only</td>
<td>Admin only</td>
</tr>
<tr>
<td><code>links</code></td>
<td>Published only (via query)</td>
<td>Published only</td>
<td>Admin only</td>
</tr>
<tr>
<td><code>users/$uid</code></td>
<td>Denied</td>
<td>Owner or admin</td>
<td>Owner (limited fields)</td>
</tr>
<tr>
<td><code>admins</code></td>
<td>Denied</td>
<td>Own status only</td>
<td>Never (console only)</td>
</tr>
<tr>
<td><code>settings/site</code></td>
<td>Allowed</td>
<td>Allowed</td>
<td>Admin only</td>
</tr>
</table>

**Principles:**
- Passwords are **never** stored manually — Firebase Auth handles identity
- User **role escalation is impossible** — protected by parent-level write rules
- Admin status verified via `admins/{uid}` — never trusted from client
- Public read is **query-scoped** to published content only
- Destructive actions require explicit confirmation

## Getting Started

### Prerequisites

- A modern web browser
- A GitHub account (for hosting)
- A Firebase project (for backend services)
- An ImgBB API key (optional, for image uploads)

### Local Development

```bash
# Clone the repository
git clone https://github.com/zishutron/zishutron.github.io.git
cd zishutron.github.io

# Open directly in browser — no build step required
open index.html
```

Firebase Setup

1. Create a project at firebase.google.com
2. Enable Authentication → Google + Email/Password
3. Create a Realtime Database (asia-southeast1 recommended)
4. Paste the security rules (see admin panel docs)
5. Update firebaseConfig in each HTML file

Deployment

```bash
git add .
git commit -m "Deploy updates"
git push origin main
```

GitHub Pages auto-deploys. Optionally, attach a custom domain via Cloudflare.
